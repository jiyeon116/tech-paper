# Provenance

This standalone repository was assembled from the QECO-Adapt research workspace
at source commit `4a6c70dac16bba5577615e50b98524fe33dfcca8`.

The initial standalone commit is the authoritative capture of the imported
QECO-ADAPT2 implementation. Only executable source code, focused tests,
launcher scripts, and result-free design documentation were imported.
Experiment outputs, logs, manuscripts, journals, archives, and paper build
assets were intentionally excluded.

The imported QECO runtime descends from `ImanRHT/QECO` at commit
`9221263c81cdbc9b31ecc4d22dd5cd3f04c338dc`; see
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for attribution and licensing.
